# 身份治理加固方案

## 已实施控制

| 风险 | Beta 控制 | 验证方式 |
| --- | --- | --- |
| 默认高权限账号泄露 | 移除预置账号；空数据设备只能初始化一次管理员 | 清空应用数据后检查首次界面 |
| 高权限公开注册 | 公开入口只允许学生、教师 | UI 与 `registerUser` 双重校验 |
| 邀请码泄露或复用 | 128 位随机码、摘要存储、角色绑定、24 小时过期、一次性消费 | 服务方法与设备回归 |
| 暴力猜测 | 连续 5 次失败后锁定 5 分钟 | 服务方法回归 |
| 管理员误停用 | 禁止停用当前管理员或唯一启用管理员 | 服务方法与管理界面回归 |

## 使用路径

```text
公开用户 ──> 学生/教师注册 ──> 普通权限
管理员 ──> 签发一次性邀请码 ──> 受控渠道交付 ──> 安保/管理员内部开通
```

内部入口保留为低显著性入口，便于被授权人员按流程找到；但安全性不依赖隐藏入口，而依赖邀请码、角色绑定、时效、一次性消费和管理员权限判断。

## 上线前门槛

- 接入校方可信身份提供方与服务端授权，替代本地账户作为正式身份源。
- 将邀请码签发、账户停用与敏感业务操作写入服务端不可篡改审计。
- 在服务端实施速率限制、风险告警、会话撤销和管理员双人复核。
- 使用生产签名、隐私声明和密钥管理策略后，才可将 Beta 安装包作为正式发布候选。
