# 本地身份治理加固上下文

范围：Beta 版本地账户、角色权限和内部人员开通流程。该范围不把本机 Preferences 误称为校园统一身份认证，也不声称具备服务端级别的防护。

## 已识别资产与边界

- 账号口令、角色、登录会话和邀请码摘要位于应用私有 Preferences。
- 安保与管理员拥有更高的业务权限；学生、教师仅能经公开入口开通。
- 设备被接管、应用数据被导出或管理员终端失守，不属于本地摘要存储能够单独抵御的边界。

## 当前实现证据

- `entry/src/main/ets/service/AccountService.ets`：PBKDF2-HMAC-SHA256、每账户随机盐、首次管理员初始化、失败登录临时锁定、限时一次性邀请码、账户停用。
- `entry/src/main/ets/pages/LoginPage.ets`：公开注册仅呈现学生/教师；内部开通入口不暴露角色选择，需管理员签发的邀请码。
- `entry/src/main/ets/pages/AccountPage.ets`：仅具有 `MANAGE_ACCOUNTS` 权限的管理员可签发邀请码或变更账号启用状态。
- `entry/src/main/ets/service/PermissionService.ets`：角色至业务操作的本机授权判断。

## 不能在 Beta 本机版中承诺的能力

- 不能抵御已解锁且受控的设备、篡改后的客户端或管理员本人主动泄露邀请码。
- 不能完成集中注销、跨设备审计、可信校园身份校验或服务器侧速率限制。
- 后续正式部署应接入学校统一身份源、服务端令牌、集中审计及设备完整性策略。
